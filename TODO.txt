# Intégration des nouvelles animations de pions

> Source de vérité : le banc d'essai `Pawn Animations.dc.html` (toutes les valeurs ci-dessous en sont extraites et testées).

## Principes (ce qui change vs l'ancien système)

Les anciennes `@keyframes` ont été pensées pour des **billes rondes centrées**. Les pions sont
maintenant des **SVG hauts** dont la base remplit la case et le corps déborde vers le haut. Donc :

1. **`transform-origin: bottom center` sur `.marble`** → tout `scale`/`translateY` pivote sur la
   base : le pion reste planté sur sa case au lieu de « décoller » en se déformant.
2. **Timeline `linear` + `animation-timing-function` PAR keyframe** → l'offset d'un keyframe (ex. `52%`)
   correspond alors à une fraction de temps RÉELLE. C'est indispensable pour **caler la réaction de la
   victime pile au contact** de l'attaquant.
3. **Synchro attaquant/victime = `animation-delay` sur la victime** (= fraction de contact × durée).
   Plus aucun `setTimeout` à gérer pour capture / enter+capture.
4. **Faisceaux, halos, étincelles, poussière = éléments overlay** ajoutés à la case (CSS ne suffit pas
   pour les particules) → petit helper `PawnFx` fourni plus bas.

## 1) SCSS — remplace ton bloc « ANIMATIONS PAR TYPE D'ACTION »

    transform-origin: bottom center;
}

    --anim-move:         180ms;   /* PAR case ; répété par case parcourue */

           animation-timing-function: cubic-bezier(.5,0,.96,.4); }      /* accélère la chute */

## 2) Helper overlay `PawnFx` (faisceaux, halos, étincelles, poussière)

Vanilla TS, sans dépendance. Chaque méthode reçoit **l'élément de la case** (`.case-path`,
qui est déjà `position: relative`) et y ajoute des overlays auto-nettoyés. Le board doit laisser
`overflow: visible` (déjà le cas) pour que faisceaux et étincelles dépassent vers le haut.

```ts
// pawn-fx.ts
export class PawnFx {
  /** Poussière à l'atterrissage (ENTER, ENTER+CAPTURE). */
  static dust(square: HTMLElement) {
    const r = square.getBoundingClientRect();
    for (let i = 0; i < 9; i++) {
      const p = document.createElement('div');
      const ang = -Math.PI / 2 + (Math.random() - .5) * 2.4;
      const dist = 30 + Math.random() * 38;
      p.className = 'pawn-fx';
      p.style.cssText =
        `position:absolute;left:50%;top:50%;width:11px;height:11px;border-radius:50%;` +
        `background:radial-gradient(circle,#cfcfd6,#8a8a93);pointer-events:none;z-index:140;`;
      square.appendChild(p);
      p.animate([
        { transform: 'translate(-50%,-50%) scale(1)', opacity: 1 },
        { transform: `translate(calc(-50% + ${Math.cos(ang) * dist}px),` +
                     `calc(-50% + ${Math.abs(Math.sin(ang)) * -dist * .4 + 6}px)) scale(0)`, opacity: 0 },
      ], { duration: 680, easing: 'cubic-bezier(.2,.6,.3,1)', fill: 'forwards' })
        .finished.then(() => p.remove()).catch(() => p.remove());
    }
  }

  /** Colonne de lumière. color: 'gold' (promotion) | 'cyan' (teleport). Retourne l'élément à animer/retirer. */
  static beam(square: HTMLElement, color: 'gold' | 'cyan'): HTMLElement {
    const grad = color === 'gold'
      ? 'linear-gradient(to top, rgba(255,235,150,.72) 0%, rgba(255,205,70,.32) 45%, rgba(255,205,70,0) 100%)'
      : 'linear-gradient(to top, rgba(205,240,255,.7) 0%, rgba(150,215,255,.3) 50%, rgba(150,215,255,0) 100%)';
    const glow = color === 'gold' ? 'rgba(255,205,80,.7)' : 'rgba(140,210,255,.75)';
    const beam = document.createElement('div');
    beam.className = 'pawn-fx';
    beam.style.cssText =
      `position:absolute;left:50%;bottom:50%;width:105%;height:320%;` +
      `transform:translateX(-50%) scaleY(0);transform-origin:bottom center;` +
      `background:${grad};border-radius:44px 44px 0 0;filter:blur(.5px);` +
      `box-shadow:0 0 30px ${glow}, inset 0 0 22px rgba(255,255,255,.5);` +
      `pointer-events:none;z-index:96;`;
    square.appendChild(beam);
    return beam;
  }

  /** Anneau de lumière qui se propage (promotion). */
  static ring(square: HTMLElement) {
    const ring = document.createElement('div');
    ring.className = 'pawn-fx';
    ring.style.cssText =
      `position:absolute;left:50%;top:50%;width:100%;height:100%;` +
      `transform:translate(-50%,-50%);border-radius:50%;` +
      `border:3px solid rgba(255,215,90,.9);box-shadow:0 0 18px rgba(255,215,90,.7);` +
      `pointer-events:none;z-index:97;`;
    square.appendChild(ring);
    ring.animate([
      { transform: 'translate(-50%,-50%) scale(.5)', opacity: .9 },
      { transform: 'translate(-50%,-50%) scale(2.7)', opacity: 0 },
    ], { duration: 900, easing: 'cubic-bezier(.2,.6,.3,1)', fill: 'forwards' })
      .finished.then(() => ring.remove()).catch(() => ring.remove());
  }

  /** Gerbe d'étincelles dorées qui montent (promotion). */
  static rise(square: HTMLElement) {
    for (let i = 0; i < 14; i++) {
      const p = document.createElement('div');
      const sz = 6 + Math.random() * 6;
      p.className = 'pawn-fx';
      p.style.cssText =
        `position:absolute;left:calc(50% + ${(Math.random() - .5) * 64}px);top:50%;` +
        `width:${sz}px;height:${sz}px;border-radius:50%;` +
        `background:radial-gradient(circle,#fff,#ffce40);box-shadow:0 0 8px rgba(255,210,90,.9);` +
        `pointer-events:none;z-index:140;`;
      square.appendChild(p);
      const rise = 120 + Math.random() * 130, sway = (Math.random() - .5) * 44;
      p.animate([
        { transform: 'translate(-50%,-50%) scale(1)', opacity: 1 },
        { transform: `translate(calc(-50% + ${sway}px), calc(-50% - ${rise}px)) scale(0)`, opacity: 0 },
      ], { duration: 900 + Math.random() * 420, easing: 'cubic-bezier(.3,.5,.4,1)', fill: 'forwards' })
        .finished.then(() => p.remove()).catch(() => p.remove());
    }
  }

  /** Animation d'apparition/disparition d'un faisceau retourné par beam(). */
  static fadeBeam(beam: HTMLElement, dir: 'in' | 'out', duration: number) {
    const f = dir === 'in'
      ? [{ opacity: 0, transform: 'translateX(-50%) scaleY(0)' },
         { opacity: 1, transform: 'translateX(-50%) scaleY(1)' }]
      : [{ opacity: 1, transform: 'translateX(-50%) scaleY(1)' },
         { opacity: 0, transform: 'translateX(-50%) scaleY(0)' }];
    return beam.animate(f, { duration, easing: dir === 'in' ? 'cubic-bezier(.3,.8,.4,1)' : 'ease-in', fill: 'forwards' });
  }
}
```

## 3) Câblage dans le composant board

### ENTER / MOVE / PROMOTION (lévitation)
Inchangé dans l'esprit : `getMarbleAnimClass(index)` renvoie `marble-entering` / `marble-moving` /
`marble-promoting`. Pour MOVE multi-cases, **rejoue `marble-moving` à chaque case** du trajet
(retire puis remets la classe, ou incrémente une clé d'animation, entre chaque case).

### CAPTURE et ENTER+CAPTURE — **aucun JS de timing**
Pose simplement les classes sur les deux pions en même temps :
- attaquant : `marble-capturing` (resp. `marble-enter-slam`)
- victime   : `marble-captured-exit` (resp. `marble-crushed`)
- case      : `square-impact` (resp. `square-enter-impact-capture`)

Le `animation-delay` interne fait réagir la victime **pile au contact**. Retire les classes /
renvoie la victime « à la maison » sur l'`animationend` de la victime.

### PROMOTION — effets overlay
```ts
const sq = this.squareEl(promoIndex);           // l'élément .case-path de la case d'arrivée
const beam = PawnFx.beam(sq, 'gold');
PawnFx.fadeBeam(beam, 'in', 420);
PawnFx.ring(sq);
setTimeout(() => PawnFx.ring(sq), 440);
PawnFx.rise(sq);
setTimeout(() => PawnFx.rise(sq), 640);
setTimeout(() => PawnFx.rise(sq), 1040);
setTimeout(() => PawnFx.fadeBeam(beam, 'out', 220).finished.then(() => beam.remove()),
           DURATION_PROMOTE - 220);
// + classe marble-promoting sur le pion pour toute la durée
```

### TELEPORT — faisceaux + swap du modèle à mi-parcours
```ts
const sqA = this.squareEl(idxA), sqB = this.squareEl(idxB);
const beamA = PawnFx.beam(sqA, 'cyan'), beamB = PawnFx.beam(sqB, 'cyan');
PawnFx.fadeBeam(beamA, 'in', 240); PawnFx.fadeBeam(beamB, 'in', 240);
// classe marble-teleporting sur les DEUX pions
const D = 880; // = --anim-teleport
setTimeout(() => this.swapMarblesInModel(idxA, idxB), D * 0.5);   // ← pendant l'invisibilité
setTimeout(() => {
  PawnFx.fadeBeam(beamA, 'out', 220).finished.then(() => beamA.remove());
  PawnFx.fadeBeam(beamB, 'out', 220).finished.then(() => beamB.remove());
}, D);
```
> Important : **ne déplace pas les pions latéralement**. On joue le flash sur place, on échange les
> données du modèle quand les deux pions sont invisibles (50 %), Angular re-rend chaque pion dans sa
> nouvelle case, et la 2ᵉ moitié du keyframe le rematérialise.

## Récap timings (fractions de contact)

| Animation        | Classe pion          | Classe victime         | Contact | Synchro            |
|------------------|----------------------|------------------------|---------|--------------------|
| Enter            | `marble-entering`    | —                      | 56 %    | `squarePress` delay |
| Move (×case)     | `marble-moving`      | —                      | —       | rejouer par case   |
| Capture          | `marble-capturing`   | `marble-captured-exit` | 52 %    | `animation-delay`  |
| Teleport         | `marble-teleporting` | (l'autre pion idem)    | 50 %    | swap modèle + beam |
| Promotion        | `marble-promoting`   | —                      | —       | PawnFx (overlays)  |
| Enter + Capture  | `marble-enter-slam`  | `marble-crushed`       | 56 %    | `animation-delay`  |
